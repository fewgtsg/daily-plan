# 每日计划

一款基于 **Tauri + React + SQLite** 构建的 Windows 桌面规划与复盘软件。它不是为了替代复杂的项目管理工具，而是将一套经过验证的每日规划方法论，转化为一个专注、私密、随时可用的本地应用。

> 📥 **直接下载安装**：https://github.com/fewgtsg/daily-plan/releases/tag/v0.1.0

---

## 设计理念

这款软件的设计灵感来源于一套 Excel 表格中的每日计划方法论。传统的表格虽然清晰，但每次打开、填写、保存都需要手动操作，历史记录也不易回溯。我们希望把这套方法论**固化成一个真正的工具**：

- **不依赖 Excel**，数据完全本地存储
- **不绑定时间段**，随时打开随时记录
- **不强制流程**，提供模板但不限制自由发挥
- **不丢失历史**，所有记录自动保存，支持全文搜索

核心设计原则是：**自由填写的电子日记本 + 动态四象限任务看板**。

## 功能详解

### 1. 每日记录（富文本日记本）

打开软件默认进入今日记录页。这里是一个富文本编辑器，你可以像写日记一样自由书写。

**核心特性**：
- **模板插入**：顶部提供 5 个方法论模板快捷插入
  - ① 锁定目标 —— 目标清晰！
  - ② 复盘过程 —— 做了什么，哪些结果达成了，哪些没做到
  - ③ 拆解问题 —— 连续问自己为什么？
  - ④ 优化行动 —— 把方案变成具体行动 5W1H
  - ⑤ 形成套路 —— 经验提炼成可以反复使用的方法论
- **自动保存**：停止输入 1 秒后自动保存到本地 SQLite，无需手动点击保存
- **日期切换**：支持前一天/后一天快速翻阅，也可通过左侧日历直接跳转
- **任务引用**：右侧栏显示当前活跃任务，点击"引用"即可将任务摘要插入正文

**设计理念**：记录不是为了打卡，而是为了沉淀。模板提供思考的脚手架，但正文完全自由，你可以写随笔、贴便签、添加自定义内容。

---

### 2. 四象限任务看板

独立的任务管理模块，采用经典的**艾森豪威尔矩阵**（重要/紧急四象限）。

**核心特性**：
- **2×2 网格布局**：四个象限颜色区分（重要紧急=暖色、重要不紧急=冷色、紧急不重要=黄色、不紧急不重要=灰色）
- **拖拽移动**：任务卡片可在象限间自由拖拽，改变优先级
- **任务生命周期**：任务创建后长期存在于看板中，直到你主动完成或删除
  - 不强制每日清空 —— 未完成的任务不会自动消失
  - 已完成的任务会变灰/划线，但仍保留在看板中供回顾
  - 可随时删除已完成的任务
- **完成关联**：点击"完成"时，可选择是否将任务引用到今天的记录中

**设计理念**：任务看板不是待办清单，而是**优先级管理工具**。我们不按日期切割任务，而是让任务围绕"重要性"和"紧急性"自然流动。这样做的原因是：很多真正重要的事情（如学习、锻炼、关系维护）并不紧急，如果按天清空，它们永远会被紧急但不重要的事情挤掉。

---

### 3. 历史搜索与回溯

**核心特性**：
- **全文搜索**：基于 SQLite FTS5 全文索引，毫秒级搜索所有记录内容和任务标题/描述
- **搜索结果**：显示记录日期、内容摘要、类型标签（记录/任务）
- **日期跳转**：点击搜索结果中的日期，直接跳转到那天的记录页
- **日历导航**：左侧迷你月历始终可见，有记录的日期会显示绿色小圆点，点击即可跳转

**设计理念**：规划的价值不仅在于当下，更在于**回顾**。当你一周后、一个月后回看自己的记录，会发现 patterns：哪些问题反复出现？哪些目标总是拖延？哪些方法论真正有效？搜索和日历让这种回顾变得异常简单。

---

### 4. 数据保护与导出

**核心特性**：
- **自动备份**：每次启动软件时，自动复制数据库到备份目录，保留最近 7 天的备份
- **JSON 导出**：设置页提供"导出全部数据为 JSON"功能，作为最原始的离线备份
- **完全离线**：不需要网络连接，所有数据保存在本地 `%APPDATA%/DailyPlan/` 目录

**设计理念**：数据是用户最宝贵的资产。我们不提供云同步（避免隐私泄露和依赖外部服务），但提供多层本地保护：自动备份防止误删，JSON 导出防止格式锁定，SQLite 单文件便于迁移。

---

### 5. 主题与交互

- **暗色/亮色模式**：右上角一键切换，适配不同时段和环境光线
- **Toast 通知**：全局错误提示，操作失败时会友好地通知用户
- **响应式布局**：三栏式界面（侧边导航 + 主内容区 + 任务引用栏），自适应窗口大小

### v0.2.0 新增
- **标签体系**：日记与任务共用标签，`#标签` 自动识别，标签管理面板，按标签搜索
- **任务双向链接**：日记中 `[[任务标题]]` 自动补全，点击跳转看板
- **布局自定义**：可折叠侧边栏，状态记忆
- **动画与过渡**：页面切换动画，看板拖拽增强反馈

## 安装方式

### 方式一：直接下载安装（推荐）

1. 访问 [GitHub Releases](https://github.com/fewgtsg/daily-plan/releases/tag/v0.1.0)
2. 下载 `.msi` 或 `.exe` 安装包
3. 双击运行，按向导完成安装

### 方式二：从源码构建

```bash
# 克隆仓库
git clone https://github.com/fewgtsg/daily-plan.git
cd daily-plan

# 安装前端依赖
npm install

# 安装 Rust 依赖并构建
cargo build

# 开发模式运行
npm run tauri dev

# 构建发布版本
npm run tauri build
```

> 构建需要安装 [Rust 工具链](https://rustup.rs/) 和 [Node.js](https://nodejs.org/)。

## 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 桌面框架 | **Tauri v2** | Rust 后端 + Webview 前端，安装包仅 ~5MB |
| 前端框架 | **React 19 + TypeScript** | 组件化 UI 开发 |
| 样式 | **Tailwind CSS + shadcn/ui** | 原子化 CSS + 无障碍组件库 |
| 富文本编辑 | **TipTap** | 基于 ProseMirror，支持 Markdown 导出 |
| 拖拽交互 | **@dnd-kit** | 四象限看板卡片拖拽 |
| 数据库 | **SQLite + rusqlite** | 本地单文件存储，含 FTS5 全文索引 |
| 日期处理 | **date-fns** | 日历计算与格式化 |

## 使用建议

### 早晨：锁定目标
打开软件，在记录页插入"① 锁定目标"模板，写下今天最重要的 1-3 件事。然后切换到四象限看板，把这些事转化为具体任务放入对应象限。

### 白天：动态调整
随时打开四象限看板查看任务。遇到新任务时立即放入看板，避免大脑缓存。完成一项任务后点击"完成"，并选择是否引用到今日记录。

### 晚上：复盘沉淀
回到记录页，插入"② 复盘过程"和"③ 拆解问题"模板，回顾今天做了什么、哪些做到了、为什么没做到。对于反复出现的问题，插入"⑤ 形成套路"模板，提炼成可复用的方法论。

### 周末：回顾搜索
使用历史搜索功能，搜索关键词（如"拖延"、"会议"、"健身"），看看这些主题在过去几周的出现频率和上下文，发现自己的行为模式。

## 项目背景

这个项目源于一张 Excel 表格中的每日计划方法论。表格里分了上午、下午、晚上三个时段，每个时段有固定的思考步骤。但 Excel 毕竟是表格工具，不适合长期使用：

- 没有历史记录的快速翻阅和搜索
- 四象限管理需要手动维护
- 任务和记录是分离的，无法关联
- 没有自动保存，容易丢失内容

所以我们决定把它做成一个真正的软件：**保留方法论的核心思想，但用现代桌面技术重新实现**，让它成为一个可以陪伴用户长期使用的工具。
